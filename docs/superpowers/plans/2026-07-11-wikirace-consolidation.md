# WikiRace consolidation plan (2026-07-11)

This plan moved the project from two local checkouts and a linked worktree to
one canonical `wikirace` repository and local root, renamed the GitHub
repository, and rebranded public copy from WikiPath to WikiRace while keeping
stable infrastructure identifiers unchanged. It finished on 2026-07-12; see
`docs/PROJECT_MAP.md` for the resulting identity rules and proof boundaries.

The task-by-task plan named local paths, archive locations, and account
identifiers on one machine, so its body is not part of this public export.
